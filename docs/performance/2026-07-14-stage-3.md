# Stage 3 release regression · 2026-07-14

## Scope and method

- Production build served with `pnpm preview`
- Headed Google Chrome 147 on the Apple M5 Pro MacBook Pro
- 1200 × 758 CSS viewport, DPR 2, 120 Hz display path
- Automatically selected quality profile: `medium`
- Development mode active with the 2023 income layer and UNDP data loaded

The benchmark records frames inside R3F's `useFrame`. The structured result was read from `window.__MUNDUS_BENCHMARK__` after the visible panel reached `complete`.

# Security policy

## Supported version

Security fixes are provided for the latest code on `main` and the latest
published V1 release. Older snapshots and unmerged branches are not supported.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability. Once the repository
is public, use **Report a vulnerability** on its **Security** tab to start a
private GitHub Security Advisory with the maintainers. GitHub only exposes this
reporter-facing feature for public repositories, so enabling it and verifying
the anonymous reporting button are immediate, blocking launch steps after the
product owner approves public visibility.

Include the affected URL or commit, reproduction steps, likely impact, and any
suggested mitigation. Do not include real credentials, personal data, or data
that belongs to another person in the report. Maintainers will acknowledge a
complete report as soon as practical and coordinate remediation and disclosure
through the private advisory.

Mundus is a static educational site. Data accuracy questions, cartographic
disagreements, and ordinary defects that do not expose security or privacy can
use public issues after the repository launches.
